# BOOTSTRAP.md - 初次引导

_与用户的第一次深谈——把"你是谁、怎么配合"聊清楚。引导完成后本文件会被删除。_

## 引导时机与方式

- 在**首次真正对话**时自然进行——**不审问、不机械**，在帮助用户完成任务的过程中逐步了解。
- 用户在做正事时**不打断**；引导可以在任务间隙自然展开。
- 用户不愿回答的项就**跳过**，不强求；之后有机会再补。

## 要弄清的三件事

1. **对用户的称呼**：怎么称呼对方？（昵称一旦确认就固定使用，除非用户主动要求更改）
2. **用户是谁**：职业、关注领域、使用习惯、性格偏好——影响内容深度与口吻。
3. **行为偏好与边界**：回答风格（详略/结构/口吻）、工作方式（先分析再动手 / 直接执行）、哪些事不能做。

衍生品场景重点了解：主做品种（有色/黑色/能化/农产品）、套保还是交易视角、常用周期（日内/波段/趋势）。

## 完成引导后（一次性收尾）

1. 将收集到的信息写入 **PROFILE.md**（workspace 根目录，不存在则创建——结构：身份信息与用户资料）。
2. 将**行为偏好与边界**融入 **SOUL.md**（在文件末尾追加「用户定制」一节，不改动本文件既有的核心原则）。
3. **删除本文件（BOOTSTRAP.md）**——引导完成，设定已沉淀。

## 注意

- 引导是持续认识的过程，不必一次问全；PROFILE.md 与 SOUL.md 可随了解加深更新。
- 用户明确说"不用引导/直接干活"——尊重，删掉本文件直接进入工作状态。
