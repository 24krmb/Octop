# 期货价格结构处理原则

取得数据后按需编写代码处理。通用的排序、对齐、缺失值、收益率和描述统计按常规方法处理；重点遵守以下期货特有口径。

## 主力价格

- 主力切换可能造成非市场性跳点。跨换月窗口计算涨跌或历史分位时，使用一致的连续或复权口径；无法处理时披露换月影响。
- 近一周、一月、三月和一年默认按日历窗口及此前最近交易日取参考点；如采用 5/20/60/250 个交易日近似，须明确说明。
- 单次上一年同期比较称为同比；季节性分析应使用多个历史年份，样本不足时降级为同期比较。

## 期限结构与展期

- 月差统一使用近月减远月；非单调曲线不得由单个合约对概括。
- 历史曲线比较应使用相同合约身份或相同到期梯度；低流动性远月降低结论置信度。
- 成交量和持仓量迁移反映目标合约的接替进度，不代表正式完成换月，也不代表展期成本。
- 正式展期状态沿用接口定义；换入成本率统一为 `target_price / current_price - 1`。

## 期现、地区与内外盘

- 基差默认使用现货减期货；接口公式不同时以返回公式为准。
- 地区现货比较前确认日期、规格、税费、交货方式、运费和单位可比。
- 内外盘比较前统一币种和单位，并核对合约月份、交易时段和交割品级；价差与价比分开表达，不称为期现基差。

## 全市场截面

- 仅对相同截止日、相同指标口径且未截断的完整品种集合排名。
- 排名前剔除基期缺失、超出合理范围或无法由基础字段复核的派生值；连续零变动且缺乏流动性证据的品种单列。
- 跨品种比较使用收益率、历史分位或统一定义的比例指标，不比较不可比的绝对价格和绝对基差。
