# 研究材料理解与比较规范

适用于研报、观点、快评和用户附件四类材料。搜索与取数流程见 `search-strategy.md`，本文只规定材料取回后的提炼、比较和依据规范。

## 四维提炼

每份材料按四个维度提炼，缺哪一维就明确标注"未提及"，不虚构补齐：

1. **核心结论**：材料的主要判断是什么（方向、目标、定性结论）。
2. **关键数据**：支撑结论的具体数字（价格、库存、供需、利润等），保留数值、单位和时间口径。
3. **研究逻辑**：从数据到结论的推理链条（假设 → 证据 → 判断），简述即可。
4. **风险**：材料自述的风险点、条件假设、失效情形；材料未提时如实说明"材料未提及风险"，不替作者编风险。

材料类型差异：

- **研报**：四维通常齐全，优先从 `report_get_detail` 的完整内容提炼。
- **观点**（周/月/季/年）：结论和逻辑为主，关键数据较少，如实反映、不强求数据维度。
- **快评**：时效性事件评述，重点提炼判断和数据，注意它可能只是片段评论而非完整研究。
- **附件**：与研报同等标准处理，先读全文再提炼，不凭文件名猜测内容。

## 先补全再提炼

列表返回的摘要/text 通常截断为 200 字，不能作为提炼依据。提炼前先取完整内容：

- 研报 → `report_get_detail(report_id=...)`
- 快评 → `viewpoint_get_dynamic_detail(source_id=...)`
- 观点 → 返回 text 被截断时，缩小 limit 或换关键词重搜定位到单条完整记录后再提炼。

## 比较框架

用户要求"比较/对比/差异/变化/分歧"时，按以下三轴组织：

1. **按时期**：同一作者、同一品种、同一材料类型在不同时间点的结论变化。按时间排序输出，标出观点转向点（如"7 月看多 → 8 月转中性"），并附各时期的原文依据。
2. **按作者**：不同研究员对同一品种/主题的分歧点与共识点。分歧要落到具体维度（方向、目标价、驱动、风险），共识同样说明，不夸大分歧。
3. **按材料类型**：研报、观点、快评、附件对同一主题的交叉验证。指出互相印证之处与矛盾之处；矛盾时并列呈现各方原文依据，不擅自调和或裁决。

比较输出建议用「对比表 + 差异说明 + 各方原文依据」三段式组织。

## 原文依据规范

- 每条核心结论附引用：材料类型 + 标题 + 作者 + 日期 + 标识（`report_id` / `source_id`）+ 原文摘句。
- 回答中明确区分「原文/接口内容」「Agent 归纳」「用户附件内容」三类来源，不混写。
- 不得改写原文数字和措辞后仍标注为原文；归纳部分用自己的话并注明是归纳。
- 观点与预测不是事实：不使用确定性口吻转述研究员判断，不做投资建议。
- 数据缺失、材料冲突或接口为空时如实说明，不编造结果。
