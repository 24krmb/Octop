# 呈现与交付

本文件用于完整报告与一般文件交付。普通研究回答可直接在对话中使用文字、表格或必要图示，不默认生成 HTML；下文全球覆盖与五层排版要求适用于完整日周报，专题文件按用户研究范围组织。移动端传播长图使用 [移动端结论长图](mobile-long-image.md)，不要把本文件规定的完整报告直接纵向截图。

移动端长图采用 [长图指引](mobile-long-image.md)，默认是金色主题、结论先行的单页 HTML；仅用户要求图片时再导出 PNG/JPG。

## 内容优先

日报、周报默认生成实际 HTML 图文文件。先设计研究解释，再用版面明确主次和证据关系。不能只把原始 Markdown 段落逐段装入卡片，也不能将“可视化”停留在建议阶段。

随包的 [report.css](../assets/report.css) 提供字体、版心、标题、图表区、证据注、表格、窄屏和打印样式。生成单文件时把样式内嵌到 `<style>`；也可按用户品牌调整。样式提供组件，不规定固定章节或主题。

完整日周报默认按统一体系排版：产品与期别、全局导读，然后依次呈现全球气候态势、区域天气演变、商品与供应链传导、综合研判、持续跟踪及来源。首屏应让读者认识 ENSO 主轴与全球状态，不能用一个局部运输事件取代这一入口。各层图文突出当期变化，避免全篇同尺寸卡片或满屏大数字。

每张图应回答一个有助于理解本期内容的问题。图旁用简短文字解释关键发现及意义；来源、时间、单位与限制随图保留。

可视表达要覆盖全局认识和商品传导，不能全用于一个地区。全球层呈现 ENSO 当前状态、预测阶段或历史对照；区域层用地图或紧凑的地区观察矩阵展示天气分布；商品层用图表或机制示意解释重要链路。选择数据真正支持的表达，缺少序列时用有出处的状态与比较表，不造曲线。极少新增的短报可以缩减图形复杂度，但仍保留全球、区域和商品的层级。

| 需要解释的问题 | 可选形式 | 关键约束 |
| --- | --- | --- |
| ENSO 当前在哪个阶段，全球主轴如何演进 | 状态与预测阶段图、同阶段历史对照 | 区分观测和预测，注明批次及有效期；无新批次仍保留有效状态 |
| 全球主要地区分别发生了什么 | 地区观察矩阵、可靠的天气或产区地图 | 区分持续异常、恢复、无重大新增和资料缺口；不把所有异常默认归因于 ENSO |
| 本次发展速度或历史位置 | 同阶段趋势图、历史区间 | 统一指标与时间对齐方式，区分预测与观测 |
| 哪些产区或通道受到影响 | 简明示意图、地区对照表 | 未核实坐标或覆盖范围时不用精确地图制造确定感 |
| 天气如何传导到商品 | 机制图、带说明的箭头关系 | 区分已有证据与待确认环节，箭头不暗示已证实因果 |
| 本次与历史有何异同 | 对照表、少量可比指标图 | 既展示相似点也展示改变结论的差异 |
| 一周内事件如何推进 | 关键节点时间线 | 区分发生、公告、生效与预计恢复时间 |

无可靠序列时用事实表或文字，不生成装饰性数据。只有采用了可信方法和数据，才输出概率、分位数、风险等级或打分。不得把示意曲线画成实测走势。

## 文件形式

报告交付同时读取 [品牌、技能来源与风险声明](brand-and-disclosure.md)，使用其中固定文字与放置规则。页眉、标题下来源栏及页脚构成统一产品标识；品牌层与研究正文分开，保留本期研究标题和五层内容结构。

- **HTML（日周报默认）**：生成易读、完整的单页研究长文，适配手机和桌面阅读。优先内嵌 CSS、SVG 或随包图形，正文与核心图表离线可读。可选的折叠、悬停只补充细节，不隐藏必要结论。无需搭建应用、依赖登录或启动服务器。返回真实文件链接，环境支持时打开预览。
- **Markdown**：普通研究对话可直接使用；报告场景中作为底稿或用户明确要求的纯文本交付，不替代日周报默认 HTML。交付文件时聊天回复用简短结论和附件入口，不重复粘贴整篇正文。
- **PDF/文档**：用户要求时使用环境已有导出工具；需要相应文档技能且环境可用时再读取。按文件形式处理分页、图表尺寸与长表，不以浏览器截图冒充完整文档。
- **移动端长图**：用户明确要求时，另行编辑为结论先行、适合手机纵向滚动的单页 HTML；用户明确要求图片文件时再导出 PNG/JPG。完整规则见 [移动端结论长图](mobile-long-image.md)。它不是日报、周报的默认替代格式。

HTML 推荐将样式及核心图形随文件打包，减少网络依赖。打印时隐藏操作按钮、展开必要内容，防止标题与正文分离、图表裁切及表格溢出。基础内容应能在脚本不可用时阅读。

同一期多种格式共享同一份内容和数据，不分别改写数字、日期或判断。文件名按 [统一命名规则](brand-and-disclosure.md#文件与样例命名) 包含产品、交付类型与截止日期。报告开头标明期别、实际覆盖区间、资料截止时间及必要的材料限制。

将时间窗口放在简洁的元信息栏。重要口径与局限就近作图注、边注或短说明；一般核验说明放来源区，不让每一段都以限制性语句收尾。保留会改变主判断的不确定性。

## 文风与视觉

采用研究简报的文字密度与层次：导读帮助快速理解，正文保留关键推理，图表承载比较。使用清晰字体、留白和克制的强调色；颜色含义一致，并辅以文字或线型，不能只靠红绿区分信息性质。

客户阅读不应依赖点击。允许轻量动画帮助解释过程，但提供静态终态和打印表达，且不将未来风险演示成既成事实。不为宣传效果放大结论，不添加未授权的品牌标识、研究员署名或机构背书。

## 交付核查

对实际生成的格式做相应检查：

- 正文、摘要、图题和图表数据一致；每张图有单位、时期、口径和真实来源。
- 确实生成了 HTML，而不是聊天中的代码片段；存在可见的研究层次与实质性图示，移除动画后内容仍完整。
- 完整日周报首个主体章节包含 ENSO 与全球态势，区域总览保留全球覆盖，商品影响能对应上游天气解释；不能以单一区域专题冒充完整日报。
- 检查桌面及窄屏阅读中的溢出、遮挡、字号和图例；导出文件打开后检查完整性与分页。
- PDF 逐页查看有无空白异常、裁切、乱码、缺图和来源丢失；交互数据在导出中保留静态表达。
- 产品标识、完整技能来源、AI 生成性质在首屏清晰可见，页脚保留风险提示与完整声明；文字归属不能暗示机构发布或审核本期报告。窄屏、打印及导出后检查标识和声明没有被隐藏、截断或遮挡正文。
- 报告末尾保留 SKILL.md 中适用的完整固定提示；正式审核说明不替代风险提示。摘要及独立图表同样保留规定的归属、风险提示及结论成立的关键条件。

只有实际生成、打开和检查过的文件才能声称已导出并验证。工具不可用时交付可用格式，说明未完成的导出项；不提供虚构附件或声称具备尚未实现的交互。
