# 接入检查与准备

本页说明默认行情源 foreign 的接入与排障。用户指定其他已接入来源时，按该来源的实际工具说明验证。

## 1. 检查所需能力

| 能力 | 如何确认 | 缺失时处理 |
| --- | --- | --- |
| 外盘 MCP | 当前可调用工具含 `get_foreign_domestic_mapping` 和 `get_foreign_market_analysis` | 引导按本文件配置 foreign；不声称行情已接入 |
| 盘前国内对照 | `futures_market_data` 的交易日历与历史行情工具可用 | 缺失时仍可给外盘观察，但不声称完成内盘对照或验证开盘反应 |
| 资讯核实 | 有公开搜索与网页正文读取能力，或用户指定的资讯工具 | 可完成行情版并标注资讯未核验 |
| HTML 生成 | 能执行 Python 3 标准库脚本，且目标目录可写 | 有其他可用文件工具时按随包样式生成并验证 HTML；完全不能写文件时明确限制，先交付正文 |
| 日期核实 | 当前可用交易日历工具或交易所公告 | 真实假期需核实休市边界；用户给定区间/明确模拟不被法定假期检查阻断 |

以当前会话可调用工具判断连接状态，凭证由客户端安全配置。不同客户端可能添加工具名前缀，或以 `futures_market_data` / `futures-market-data` 作为 server 别名；按实际功能和 schema 匹配，复用已验证的一套，不重复调用别名工具。

首次取数、连接变化或调用报错时检查连接；正常追问复用已有配置，更新报告时重新查询行情。

## 2. 配置 foreign

- Server 名称：`foreign`。
- URL：`https://track.finoview.com.cn/fiona/mcp/foreign`。
- 传输：Streamable HTTP；平台配置字段拼写以随包对应模板为参考。
- 鉴权：`Authorization: Bearer <API Key>`。API Key 暂不支持在线自助申请，请联系繁微对口销售或项目联系人获取。

按用户实际平台选一个模板；不确定平台且需要配置时才询问。不覆盖原有配置，只合并缺少的 foreign 项。已经明确授权配置时继续执行授权范围内的操作；只有用户要求生成报告而未授权修改客户端时，提供接入指引，不自行改配置。真实 Key 由用户在客户端安全凭证区填写，模板占位符不能作为真实凭证测试，也不能提交替换后的密钥文件。

- [Claude 配置参考](../templates/claude/mcp.json)
- [OpenCode 配置参考](../templates/opencode/mcp.json)
- [OpenClaw 配置参考](../templates/openclaw/mcp.json)
- [WorkBuddy 配置参考](../templates/workbuddy/mcp.json)

模板尚未在所有客户端实装验证；若字段不被支持，核对该客户端当前配置规范。填入凭证后按客户端要求重新加载工具，再用实际调用验证连接。

盘前还使用 `https://track.finoview.com.cn/fiona/mcp/futures_market_data`，当前公开免鉴权，不添加 Authorization。可选 `news` 与 `economic_calendar` 的鉴权和端点见 [Optional MCP 指南](optional-mcp.md)。随包客户端模板仅包含 foreign，其他服务按实际任务和已有授权补充。

## 3. 用本次任务的小查询验证

1. 读取两个工具实际 schema。先调用 `get_foreign_domestic_mapping`：用户指定品种时用该品种；多品种或全范围请求可不传 `domestic_code`、`domestic_name` 一次取全量目录并本地筛选，记录返回 total 与实际覆盖；单品种优先精确筛选，已获取目录则复用。
2. 核对映射返回的外盘名称、交易所、代码、单位、合约类型与多重映射；不存在映射时说明品种未覆盖，不猜外盘代码。只有映射返回成功，仅证明映射调用成功。
3. 从已返回的映射选一项，用 `get_foreign_market_analysis` 查询目标窗口内的小范围行情。先取最少必要端点/摘要，确需序列才开启；分钟序列参数为频度、条数与价格类型三类（1m 档不接受 `aggregation`；超限先降频、降到 60m 仍超限则丢掉最老一段），详见 [数据接入与行情口径](data-method.md)。日期格式、参数名与取值范围以当前 schema 为准，不编造覆盖范围工具或 API 签名。
4. 核对有效价格、记录时间、价格单位、合约类型（主力连续 / 三个月连续 / 连一、连二、连三）与返回频度；北京时间、合约选取口径和分钟 `last` 沿用本技能约定，不将底层实际合约或换月明细列为接入验收项。一次有效查询证明该标的该窗口可用，不证明全部标的和全部历史均可用。返回为空时检查窗口是否交易、是否整段早于行情记录起点（2026-08-26 18:00 北京时间）、保留期与参数，不直接判定 Key 错误。
5. 扩展至本次报告范围，逐项核实基准和末值。历史覆盖以接口元信息或实际查询为准；序列截断与完整历史保留范围须区分，处理方法见 [数据接入与行情口径](data-method.md)。

数据新鲜度按实际返回时间与海外交易安排判断。正常休市造成的报价间隔予以说明；交易期间数据未更新时披露截止与缺口。

## 4. 错误与继续条件

| 状态 | 下一步 |
| --- | --- |
| 工具缺失 | 检查服务配置、工具加载和客户端支持；不能声称已测试服务器 |
| `401` / `403` | 检查 Key 是否配置、有效、具有 foreign 权限；不猜测其他端点可共用凭证，不反复重试 |
| 超时 / 连接拒绝 / transport error | 检查 URL、网络和客户端传输支持；临时错误最多重试一次，仍失败说明连接不可用 |
| 映射成功、行情失败 | 分别说明成功和失败项，不把目录可读等同于行情已可用 |
| `400`（与 `aggregation` 相关） | 解析后的频度是 1m：1m 档每桶只有一条记录、无价格类型可选。显式指定 5m 或更粗频度，或去掉 `aggregation`；不当作鉴权或排序问题 |
| 参数限额与 Skill 文档不一致 | 记录当前 schema／错误提示和实际连接；采用当前可接受参数完成任务，并披露兼容限制。较低限额不代表目标规范已变更，不反复尝试超限值或拆分序列绕过限制 |
| 返回成功但无记录 | 核对交易时间、窗口、参数和历史覆盖；按用户允许的范围换近期窗口，不能静默改明确指定的日期 |
| 部分标的缺失或时间不同 | 继续可用部分，披露每项实际覆盖，排除不满足可比条件的项 |

接入问题只在影响本次任务时说明，写清已完成部分、缺项及下一步。仍无可比行情时，可交付已核实的资讯部分并明确覆盖缺口。

交易安排通过已有交易日历工具或交易所公告核实。
