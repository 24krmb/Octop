# 数据接入与行情口径

本页是盘前、假期及自定义区间共用的行情规范。首次使用或连接异常时按 [接入检查与准备](setup.md) 验证工具与小范围行情，已验证连接直接复用；参数名、枚举字面值以当前 schema 为准，不猜造接口字段。用户指定其他来源时注明其实际价格定义、合约、单位、时区和覆盖。

## 时间与覆盖

- foreign 时间按北京时间解释；无时区字符串按服务约定补 `+08:00`，不是从 UTC 转换。底稿保留原时间字符串。其他来源按其明确时区换算。
- 外盘行情自 **2026-08-26 18:00（北京时间）** 开始积累。全区间早于该时刻时无法用此源验证，建议更换近期区间或提供同口径历史资料。起点更早但跨越该时刻时，按实际首条记录报告可用起点和缺口，不能把积累起点当成每个标的都存在报价的时刻。
- 数据起点不保证此后每分钟都有数据，也不保证永久保留全部历史。优先读实际覆盖信息；没有覆盖端点时以查询返回判断，不臆造覆盖工具，不把序列截断误判为历史保留范围。
- 明确给定的请求区间不得静默缩短。用户授权自行选择测试区间时，可在真实可用范围内选近期一周并说明实际窗口。
- “最新”指最新已同步数据。同步计划、生成时间、检索时间均不等于报价时间；同步时间仅在服务返回时显示。结合交易安排区分正常休市与缺失，披露每项实际记录首末时间。末条早于工具描述的预计同步时刻，不能据此认定异常或归因为“同步未完成”；只报告观察到的覆盖缺口，原因须有服务状态或源方证据支持。

## 合约与标的

`get_foreign_domestic_mapping()` 无参可返回全量映射。多品种请求可一次取目录后筛选、在同一任务中复用；单品种可按代码精确查询。记录返回的 total 和本次选定范围，目录规模和板块不固化到 Skill。

`get_foreign_domestic_mapping` 按市场规则返回合约类型，交付时按实际类型标注：

- 多数品种：按成交量换月的主力连续。
- LME：三个月连续。
- 新加坡交易所、马来西亚交易所：按成交量稳定性在连一、连二、连三中选择，不统一当作成交量换月主连。

映射与行情显示的类型不一致时先核对并披露，不能把不同口径拼接；无法确认则不做可比计算。正常使用无需逐次索要底层合约、逐笔数据和换月明细。连续价格可能含换月影响，不等于固定合约持有收益，也不能据此声称已复权。

外盘按“交易所 + 代码 + 价格口径”去重；代码未返回时用交易所与名称并注明代码未提供。一项可关联多个国内品种；不同交易所的同类商品分别保留。映射目录不证明行情可用，“直接／近／间接相关”不是统计系数或传导比例。

## 明显背离与不连续的核查

多个映射先比较原始统计及各自实际覆盖；方向不同或幅度不同本身不证明数据错误。出现难以解释的明显背离、离散跳变或价格／单位异常时，再对可疑标的取适当粗频序列（例如 60m）检查路径，不要求所有多映射任务都额外拉序列或统一套固定阈值。

先核对时区、端点、单位、币种及合约类型；同口径才比较同期价差／价比。分桶标签仅用于定位可疑时段，不是跳变精确发生时刻，诊断序列不用于重算区间涨跌。必要时核对源方合约或换月资料；价格跳变只能支持“疑似不连续”，不能单凭形状确认换月，也不自行平滑、复权或删掉跳变。

原因未核实时保留原始统计与疑点，避免将其作为同组强弱结论；可比性确实存疑时令 `comparable=false`，退出排名但保留明细。可用 note：“该标的在……时段出现离散跳变，原始区间统计为……；原因未核实，暂不作同组可比解读。”不要将一次具体原油样本写成所有品种的固定规则。

## 分钟序列参数

需要路径或图表时才用 `include_series` 开启序列。**`frequency`、`max_points`、`aggregation` 只影响分钟序列；行情统计始终基于原始数据、按原始粒度计算。不得使用分桶后的序列端点计算区间涨跌，也不能用序列最高最低替代原始区间高低价。**

### 频度与条数

未传 `frequency` 或传空串时，先按查询跨度自动分档：

| 查询跨度 | 初始频度 |
| --- | --- |
| ≤25 小时 | 1m |
| >25 小时且 ≤3 天 | 5m |
| >3 天且 ≤5 天 | 15m |
| >5 天且 ≤8 天 | 30m |
| >8 天 | 60m |

- `max_points` 默认 **1500**，取值 **1~1500**，**1500 为硬上限**。此限制仅作用于分钟序列，不改变原始区间统计。
- 初始频度确定后，若按跨度估算条数超过 `max_points`，沿 **1m→5m→15m→30m→60m** 逐级降频。手动指定频度时从指定档开始校验，只允许向更粗频度调整，不自动调细。
- 降频只根据查询跨度估算，与品种及实际数据条数无关；不要因某品种休市或数据稀疏而推断服务器会保留更细频度。
- 降至 60m 仍超过 `max_points` 时，保留区间最新的一段，丢弃最老数据。完整性以**实际返回频度、首末时间和条数**核对，不以理论桶数或“请求成功”证明完整。
- 统计覆盖与序列覆盖分别记录。序列被截断不代表原始区间统计也被截断；统计有效不代表图表序列覆盖了整个窗口。

### 聚合

`aggregation` 支持桶内最新价格（默认）、最早价格、最高价格、最低价格。发送参数时先查 schema 的具体枚举，不把中文含义直接当枚举值。

- 按整点划分时间桶，以左边界作标签，例如 5m 的 21:00 桶为 21:00:00—21:04:59。
- 桶内无数据则没有该桶记录，间隔可能大于名义频度。
- **1m 禁止传入 `aggregation`，传入返回 400**，包括未指定频度、自动分档为 1m 的情况。默认 1m 请求也应省略这个参数，不能为了“显式默认值”而传入。
- 短区间确需聚合时，显式指定 5m 或更粗频度；不要依赖超限降频来规避 1m 参数限制。
- 桶标签不是桶内价格的实际发生时刻。粗档最新价可能发生在标签之后，最高／最低价更不能视作端点报价。序列仅用于对应频度的路径与展示，不用于还原精确端点或推算整段涨跌。

## 原始统计与计算端点

foreign 原始数据为分钟粒度的 `last`；行情统计中的最早价和最新价对应查询窗口内首末有效原始记录。字段名称按实际返回识别，不把名为 open 的字段擅自解释为交易所当日开盘价。

### 窗口内表现：盘前与普通区间查询

优先使用目标窗口的**原始区间统计**涨跌幅、最早价／最新价及其实际时间。原始端点可核实时可按 `(终值 / 基准价 - 1) × 100` 复算；不能从降频或聚合序列取两端替代。国内分钟行情过滤到目标窗口后使用原始 `close` 计算。缺少统计端点或原始时间时说明无法核实的字段，不用桶标签补造。

生成窗口内首末报告时设置 `endpoint_mode: "in_window"`，渲染器允许窗口内的不同实际起点并自动披露口径；排名表示各标的实际可得区间表现，不冒称统一节前基准。

### 累计观察：假期与指定基准的区间报告

此口径使用 `endpoint_mode: "pre_window_anchor"`（渲染器兼容旧底稿的默认值）。默认基准取观察起点或之前最近的同口径有效**原始报价**，终值取截止或之前最近的有效原始报价，且终值须落在观察窗口内。基准是显式窗口前锚点，不能以窗口内首价冒充节前价格。

优先用能够验证这些边界的原始统计字段／原始记录。确需核实窗口前基准时，可查询截至基准时刻的锚点行情；这是验证计算边界，不是拆分分钟序列绕过条数限制。不要用粗频桶标签或聚合值充当锚点。

- 接口统计的窗口首价与指定基准一致时可直接使用其涨跌幅；不一致时仅用已核实的同口径原始两端价格重算，记录原始价格、时刻及来源。
- 基准缺失而窗口内有有效原始统计时，可展示“实际可得区间表现”，注明实际起点并退出统一基准排名。用户明确要窗口内首末比较时遵从，写清该口径，不称为完整假期累计变化。
- 基准较陈旧时先核对交易安排，正常休市披露即可；异常缺口或无法解释的旧报价不纳入可比排名。
- 至少需要两条不同时间的有效记录；全程休市且只有窗口前报价时只展示最近报价，不伪造 0% 涨跌。

计算保留精度，展示通常两位小数。基准为零或负数不做普通百分比排名，按需展示绝对变化；缺失不是零。不同起点须逐项披露，不将中途开始的表现放进完整假期排名。原币种涨跌与人民币折算分开。

统计高低价使用原始区间统计。图表数据按时间去重、排序并核对缺口，截断序列不得画成完整区间。最大回撤、波动率等另算指标必须说明样本、实际频度与完整性；没有完整原始路径时不能声称是原始粒度的整段指标。

## 汇率、价差与外部报价

跨市场价差／价比需先统一单位、币种、价格类型和时点。具体汇率记录与计算见 [汇率数据与换算](exchange-rate.md)。缺少同区间可比汇率时注明“按原币种统计，未计汇率影响”，继续可用部分，不以美元指数替代 USD/CNY，也不把当前汇率用于历史区间。

用户要求公开报价时打开原网页，核实标的、合约、单位、币种、报价时间及时区和延迟说明，并记录检索时间。搜索摘要、访问时间和新闻发布时间都不能代替报价时间。单个公开报价可单列补充，不能与另一来源的基准价拼接计算区间涨跌。
