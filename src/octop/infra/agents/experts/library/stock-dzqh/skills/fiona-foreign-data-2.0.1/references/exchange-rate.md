# 汇率数据与换算指南

## 核心原则（Skill 层）

- 当需要将外盘价格换算为与内盘一致的币种时，模型应：
  1. 尝试通过 MCP 返回的单位字段判断是否需要换算；
  2. 在回复中说明所用汇率的**来源**与**查询时间**；
  3. 若无法获取汇率，明确告知用户并提供可选操作（例如用户提供汇率或允许模型尝试网页检索）。

## 推荐数据源（说明用途，不强制）

- 中国外汇交易中心（ChinaMoney）——当日中间价（参考）：https://www.chinamoney.com.cn/chinese/mkdatapfx/
- 备用：公共汇率 API（如 exchangerate.host）或权威金融网站（如新浪财经、东方财富）用于临时抓取。

## 字段与口径（模型应按此格式报告）

- 建议的输出字段：`pair`（货币对，如 `USD/CNY`）、`rate`（中间价或基准价）、`timestamp`（查询时间，注明时区）、`source`（数据来源）。
- 建议使用“中间价/基准价”进行换算：
  - 计算：外盘价（外币） × 汇率（每单位外币兑换的本币数） = 本币价

## 当无法自动换算时（模型应如何处理）

- 明确说明：无法获取汇率；可请求用户提供当日汇率；或尝试网页检索并在结果中列出检索来源与时间。

## 合规与免责声明

- 汇率仅作参考换算用途，非交易结算价。输出应包含免责声明：基于参考汇率进行换算，存在一定差异，不构成交易指示。

## 同区间折算与价差

历史窗口使用匹配原始价格端点的同口径汇率，记录实际首末时间；不混用 CNY、CNH、中间价和即期价，不以当前汇率替代历史数据。若汇率为每单位外币兑换的人民币数，人民币折算变化为 `(1 + 外币价格涨跌) × (期末汇率 / 期初汇率) - 1`，作为独立补充，不改变原币种排名，不称为国内期货应涨应跌幅。价差／价比还须统一数量单位、合约及价格定义；无法统一时不输出可比计算。
