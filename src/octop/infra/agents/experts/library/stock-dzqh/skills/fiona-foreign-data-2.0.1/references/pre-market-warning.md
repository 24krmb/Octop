# 盘前预警取数规则

用于内盘停止交易后、下一次开盘前的外盘跟踪。共用价格统计、频度、合约类型与历史起点规则见 [数据接入与行情口径](data-method.md)。国内对照使用 `/mcp/futures_market_data`。同一任务已读取共用口径后不重复加载；无需文件输出时不读 HTML 参考，连接正常时不读接入参考。

## 窗口选择

用户明确给出窗口时优先照用。未指定时按北京时间、实际交易日和该品种交易安排选择：

| 场景 | 推荐查询时段 | 国内对照 | 外盘统计窗口 |
| --- | --- | --- | --- |
| 日盘盘前 | 08:30—09:00 | 最近已结束的有效夜盘时段 | 该夜盘实际收盘至提问时刻 |
| 夜盘盘前 | 20:30—21:00 | 当日 09:00—15:00 日盘，按品种实际时段 | 日盘实际收盘至提问时刻 |

日盘盘前通常对应早于 09:00 的提问；夜盘盘前通常对应 15:00—21:00 的提问。明确指定场景时不以提问时钟覆盖用户意图。09:00—15:00 或其他非标准盘前时段，区间不明确时询问所需窗口；上下文足以判断时说明采用的区间。

品种无夜盘、节前取消夜盘或节后首次开盘时，回溯该品种最近实际交易时段的收盘，不虚构夜盘。无夜盘的品种不生成“今晚该品种开盘”判断。请求整个假期累计表现时转 [假期与区间观察](interval-watch.md)，而不是只看最近一夜。

## 交易日与实际日期

使用 `get_futures_trading_calendar` 查询覆盖目标日期的交易日列表，确认当日及前一个交易日，不能用自然日减一。`get_latest_futures_trading_date` 是最近交易日辅助查询，可能返回今天，不能直接等同“上一交易日”；`get_next_futures_trading_date` 可确认指定日期之后的下一交易日。日历只证明交易日期，不能单凭它确认节前夜盘取消或品种开收市时刻；夜盘安排结合映射、交易所公告及必要的实际行情时间戳核实。夜盘的业务交易日标签可能属于下一交易日，但查询必须用记录实际自然日期。

例如周一日盘前，最近夜盘可能发生在上周五晚间至周六凌晨，应按该品种实际开闭市时刻查询；长假前后尤其需核实是否开夜盘。文档和变量统一用“前一个交易日”，不要用含糊的“前一天”。

先计算带日期的 `start_datetime`、`end_datetime`。国内接口的业务日期加夜盘时间切片可能返回另一个自然日，返回后必须读取每条原始记录时间、转换北京时间、过滤到目标窗口并排序。缺失时间或越界记录剔除，不能仅用请求参数证明覆盖。两市场时间不要求逐点一致，不插值制造报价。

## 取数、统计与图表

1. 根据实际工具能力获取映射，确认国内品种、外盘标的、合约类型及交易安排；保留多重映射，不把映射类别当相关系数。
2. 用 `get_futures_timeseries_quotes` / `get_futures_dominant_quotes` 获取国内原始行情；需代码转换时用 `get_futures_product_info`。国内分钟以 `close` 为对照口径，计算前校验真实时间戳。
3. 用 `get_foreign_market_analysis` 获取内盘收盘后目标窗口的**原始区间统计**。涨跌优先用统计字段；复算仅用该窗口内首末有效原始价格及实际时刻，**不用分桶序列端点**。
4. 图表需要时另开 `include_series`，按实际返回频度和首末标签绘制。用户要求全天背景图时，图表窗口可宽于收盘后统计窗口，但必须分别标注，不能把全天统计用作收盘后信号。
5. 汇总内盘收盘、外盘涨跌和覆盖；数据足够时可给可能高开／低开／中性的辅助判断及限制，不机械按正负号推导所有映射，不承诺国内开盘或全天方向。
6. 用户要求历史分位、波动率或映射误差时才取匹配样本计算，注明样本、频度和缺失；无历史证据不得编造系数、阈值或置信区间。资讯是候选解释，不自动成立因果。

外盘统计的原始首末时间也须落在目标窗口，不能拿序列桶标签冒充。如果统计返回异常越界而原始记录不可得，说明无法核实，不自行用粗频序列“修复”统计。序列因左边界标签早于请求起点时，按桶范围解释并标注，不能由标签反推原始端点。

## 同步延迟与公开补充

外盘是已同步快照，非实时；推荐查询时段是使用建议，不是覆盖承诺。工具说明中的预计同步时刻只描述调度，不代表原始行情截止时间。输出只报告实际末条记录及与请求截止的差距，未经验证不把缺口解释为同步失败、上游延迟或窗口截断；也不因末条早于预计同步时刻就认定数据异常。

在推荐时段前查询时，先取可用部分并说明可能尚未同步，建议稍后复核；用户明确仍要立即查看或已要求公开报价补充时，可使用 Web Search，注明来源、URL、报价时间、检索时间与实际合约。无需重复征求已有授权。公开数据与 MCP 分列，不能跨来源拼接涨跌。普通同期新闻检索不受此报价补充条件限制。

## 输出至少说明

- 国内品种、代码、合约口径和实际收盘价；对应外盘交易所、标的、合约类型、单位与映射。
- 请求窗口、两市场原始数据实际首末时间、涨跌计算端点；有序列时另列频度、条数、首末标签和截断情况。
- 数据末条与提问／开盘之间的覆盖空档，按实际返回标注；区分已核实的休市安排与原因尚未确认的缺口。
- 有依据的方向参考及不确定性、新闻来源和汇率限制；末尾附 [固定风险提示](disclosure.md)。

不足两条有效原始记录时标为“无法计算”；数据缺失不填零、不拿理论端点或其他品种补齐。仅映射可用时仍交付映射并说明行情缺口。
