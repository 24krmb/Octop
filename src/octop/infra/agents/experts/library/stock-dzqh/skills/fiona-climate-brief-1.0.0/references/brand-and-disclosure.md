# 品牌、技能来源与风险声明

本文件统一可展示产出物的产品标识与声明。日报、周报、专题报告、移动端长图及其 HTML、PDF、文档、图片、纯文本版本均适用；普通研究对话按内容附风险提示，不需要模拟页眉页脚或生成报告。技能来源标识不替代事实引用，也不代表报告已获机构审核。

## 统一命名与归属

- 技能标识及目录名：`fiona-climate-brief`；保持现有调用名称。
- 中文展示名、文档标题及产出物品牌：**繁微 Fiona 气候与大宗商品观察**。
- 英文展示名：**Fiona Climate and Commodities**。
- 框架来源：**少量数据处理流程及研究框架来自于东证衍生品研究院**。
- 生成性质：**AI 辅助生成 · 仅供信息参考与研究辅助**。
- 简短提示：**期货及衍生品交易风险较高，本内容不构成投资建议。**

展示名与 `SKILL.md` 的 `display_name`、`agents/openai.yaml` 保持一致。来源表述与仓库固定风险提示一致，不把全部数据或报告结论归给研究院，不暗示本期报告由机构发布、审核或背书。不自行添加机构徽标、研究员签名、执业编号或版权归属。

## 放置与样式

| 位置 | 内容 |
| --- | --- |
| HTML 页眉／报告封面上方 | 产品标识与期别、日期。产品标识和本期研究标题分开，不能用品牌替代研究标题 |
| 标题下方的来源栏 | 完整技能来源、生成性质，以及“AI 生成内容不代表该院及其研究人员观点，未经其审核或背书”的说明；紧邻资料截止时间，首屏可见 |
| 报告页脚 | 再次出现产品标识、技能来源和简短风险提示，随后提供完整的“风险提示与免责声明” |
| PDF／文档续页 | 精简产品页眉，页脚保留简短风险提示与实际页码；完整技能来源和声明至少保留在首页来源栏与末尾声明区 |
| 单独导出的摘要或图表 | 保留产品标识、技能来源、AI 生成性质及简短风险提示；图表另保留原始数据来源和时点 |
| 移动端长图 | 头部先给研究结论并保留产品标识、期别和截止时间；尾部保留技能来源、AI 生成性质、主要数据来源及风险提示。只有目标地址真实且获用户授权时才加入二维码 |

声明以真实正文写入，不折叠、不仅放在悬停信息中、不随打印隐藏。手机端保持可读字号；分页允许声明自然跨页。

## 固定提示的使用

普通与加强提示的唯一文案维护在 [SKILL.md 的风险提示与免责声明](../SKILL.md#风险提示与免责声明)，与 `finoview-reports` 的固定文案一致，原样使用。

- 仅查询、整理、计算或复述数据使用普通提示。
- 涉及方向、趋势、强弱、结构含义、影响、情景、风险、原因推断或交易决策使用加强提示；分析型日报、周报、专题和长图均适用。
- 配置、报错、澄清无需提示。
- 提示放在回答及产出物末尾；结构化输出用 `risk_level` 和 `risk_disclaimer` 携带同一提示。
- 气候预测修订、历史比较限制、区域归因及价格传导条件写在对应正文中，不改写固定提示来容纳这些细节。

## 文件与样例命名

产出文件采用 `气候大宗商品观察_<日报|周报|专题|长图>_YYYYMMDD.html`，日期为覆盖截止日；多份专题可追加主题，用户指定文件名时遵从。产出文件格式与正文客户可见栏目名分别处理。

使用文档位于 `docs/fiona-climate-brief/introduction_fiona-climate-brief.md`，截图放同目录的 `assets/`，与报告使用相同文件名主体。用户提供的历史样例可保留原貌，文档应标明其原始日期、旧版归属文字及未重新核验的状态；新产出遵守当前规则。
