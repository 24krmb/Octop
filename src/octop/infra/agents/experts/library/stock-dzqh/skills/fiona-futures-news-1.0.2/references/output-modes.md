# 场景输出指引

按用户任务选择必要栏目，不机械套用全部模板。

## 默认时间口径

- 一般市场或品种资讯：“最近”默认过去 24 小时。
- 规则和公告：“最近”默认过去 7 天。
- 主题最新进展：默认重点检索过去 72 小时，并补充理解事件所需的早期节点。
- “今天交易日”覆盖上一有效夜盘至当前日盘；尚未收盘时标明这是盘中报告。
- “昨晚到今天”先确认实际交易日历和交易时段，不把休市时段写成夜盘。

## 全市场或品种要闻

- 检索范围与截止时间
- 重要事件：发生了什么、来源、相关品种、为什么重要
- 影响研判：方向、期限、传导路径和不确定性

按重要性排序并合并同一事件的重复报道。

## 主题与发展脉络

- 当前结论
- 关键时间线
- 已确认事实与各方表态
- 涉及品种及影响路径
- 可能的升级、缓和情景
- 后续观察信号

## 法规与交易规则

- 发布机构、文件或公告链接
- 发布日期与生效日期
- 涉及品种和交易者
- 核心变化
- 交易者需要注意的实际影响

区分征求意见、正式发布和已经生效。

## 早报、晚报与产业链日报

先写统计区间，再按需选择：

- 隔夜或当日核心事件
- 品种与板块表现
- 产业链重要变化
- 政策、事故与风险提示
- 当日或下一时段观察重点

用户未指定时，早报可覆盖前一日 17:00 至当日 08:30，晚报可覆盖当日 08:30 至 17:00；遇节假日或周末时说明实际覆盖区间。

## 行情异动归因

- 行情事实与异动时点
- 同期候选事件
- 每个事件的时间匹配、影响逻辑和证据强度
- 无法解释的部分

不要为了给出原因而强行归因。

## 事故与突发事件核查

- 是否有可靠报道或官方确认
- 事故时间、地点、设施和运营主体
- 停产、损失、产能及恢复时间等已知信息
- 相关企业、产业链和期货品种
- 尚未确认的说法
- 可能影响及后续观察点

## 利多利空与后续演变

- 短期与中期影响分别判断
- 写明传导路径和成立条件
- 补充反向因素及市场可能已经计价的部分
- 用情景分析表达后续发展，不输出确定性价格结论
