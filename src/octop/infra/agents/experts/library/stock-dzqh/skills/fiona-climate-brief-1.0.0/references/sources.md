# 来源与证据

## 可用来源与检索路径

以公开来源独立完成任务。具体研究从问题需要的气象、产业或市场证据切入，按需补齐上游背景与下游验证，不为简单查询额外检索全球。全球跟踪和完整日周报按 [全球观察体系](observation-framework.md) 先取 ENSO 及全球气候资料，再扫描主要地区，最后验证商品与运输链路。下列机构入口可以按可访问性替换，但完整日周报所需的全球气候和地区覆盖不能因某条局部消息更容易检索而省略。进入当期公告、报告或数据页面核对内容，机构入口不是具体数字的充分引用。

| 信息需要 | 优先寻找的资料 |
| --- | --- |
| ENSO 状态、预测及历史批次 | [NOAA CPC 诊断与归档入口](https://www.cpc.ncep.noaa.gov/products/analysis_monitoring/enso_advisory/)，WMO 发布的 El Niño/La Niña Update；按需查相关国家气象机构 |
| 全球和地区气候背景 | [Copernicus 气候公报](https://climate.copernicus.eu/climate-bulletin)，当地气象、水文机构的观测与预警 |
| 农业供需与预估修订 | [FAO 谷物供需简报](https://www.fao.org/worldfoodsituation/csdb)，相关农业部门、官方作物进度及供需报告 |
| 通行与运输约束 | 运河、港口、航道管理机构的航运公告、水位资料、运营数据；媒体用于补充实际影响 |
| 停产、恢复与企业影响 | 运营企业公告、监管披露、行业机构及有明确采访或数据来源的可靠媒体 |
| 市场反应 | 交易所、可用行情服务及可靠市场报道；核对标的、合约、时间、计价单位和历史调整方式 |

来源入口可能改版或当期文件无法访问。使用站内公告列表、机构名称与报告名称检索定位，不猜造链接。网页页脚更新时间不能代替正文发布日期；搜索摘要只用于发现线索。

全球扫描宜结合地区原文名称与英文检索，必要时使用当地语言。重点核对产区、设施和风暴实体，避免同名、译名或海盆混淆。多个媒体转载同一来源不算独立验证。

## 证据粒度

每个重要事件在取材时保留足以支持复核的信息，可用简短笔记或表格，不要求固定文件格式：

- 事件与地区、相关商品或设施；
- 发生时间、资料发布时间、预测有效期或限制生效时间；
- 来源机构、原文链接、直接支持的事实；
- 关键数字的单位、范围、基期、窗口及其观测/估计/预测性质；
- 与此前批次的实际变化、相反证据、未验证的推断。

输出时把关键来源就近放在对应事实或段落末，格式为 `[机构：资料标题，发布日期](原文链接)`，字段只写已核实内容。引用预测时保留机构归属，自己的推断另句表达。来源目录可以放文末作为补充。

## 冲突与不可访问

- 优先理解不同时间、区域、作物年度、单位或统计口径，再判断资料是否真正矛盾。不挑选最支持主标题的一组数字。
- 重要冲突尚未解决时展示差异及其对判断的限制，不平均两个不可比数字。
- 官方原文不可读时，可采用可靠完整转载或明确引述的报道，并标注转引。没有可靠支持的精确数字应删去或列为待核验，不凭搜索摘要包装成官方确认。
- 付费数据不可访问时使用可验证的公开替代，说明覆盖范围；不默认要求用户购买服务。
- 用户只提供旧稿且禁止联网时，可做编辑与逻辑梳理，但保留材料截止日期和“未独立核验”说明；不得把它更新成当日事实。

## 防止时间泄漏和口径漂移

历史时点写作优先找归档批次。滚动更新页上的最新值不能证明过去某日已知该值；找不到旧批次就说明无法还原。只知道发布日期而不知道具体发布时间，且落在截止日当天时，注明时点不确定，不声称已验证盘前可知。

图表和正文使用同一批数据。同比、环比、预测修订、累计变化各写清比较对象。使用原始数据重算的，记录来源与计算口径；图示关系不冒充统计估计。
