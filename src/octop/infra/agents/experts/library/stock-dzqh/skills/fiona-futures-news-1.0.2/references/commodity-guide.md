# 品种检索指引

仅在品种名称需要扩展、产业链检索或实体消歧时读取本文件。

## 检索扩展

不要只搜索品种中文名，按问题需要组合：

- 标准中文名、常见别名、英文名和期货代码
- 上游原料、下游产品、替代品和副产品
- 主产区、主销区、港口、运输通道和库存节点
- 主要生产商、贸易商、加工企业和消费行业
- 产量、开工、库存、进出口、利润、政策、天气、事故和物流等事件词

能够从上下文可靠识别时直接使用；标准名称、代码、交易所、板块或同名实体存在不确定性时，先通过可靠来源核实。无法确认时保留歧义并向用户说明，不生成看似合理的名称映射。

## 实体消歧

结合实体类型和上下文判断，不使用单一关键词定类：

- 公司、品牌与同名商品：如 Apple Inc. 与苹果期货。
- 国家、地区、企业简称与期货代码。
- 现货商品、期货品种、合约代码与股票代码。
- 某企业发生事件不代表对应品种必然受到显著影响；继续核查其产品、产能和产业链位置。

## 关系强度

按以下次序判断新闻与品种的关系：

1. 直接涉及供给、需求、库存、成本、政策或合约规则。
2. 涉及上游、下游、替代品、运输或关键企业。
3. 通过汇率、利率、风险偏好或地缘局势间接传导。
4. 仅有字面重合或缺少可说明的影响路径时，视为无关或弱相关。
