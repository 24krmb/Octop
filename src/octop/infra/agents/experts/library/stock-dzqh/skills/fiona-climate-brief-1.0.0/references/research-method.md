# 研究判断与比较口径

本文件用于研究问答、专题分析及报告中的产业判断。按问题选用方法，不要求每次执行全部比较或生成报告。用户从期货价格、基差或物流异动切入时，先明确要解释的变化，再核对天气链路及其他供需驱动；不能因为使用气候 Skill，就预先认定天气是主因。

## 从天气到商品：沿证据解释到可支持的位置

按任务选择相关环节：气象状态及预测 → 地区暴露 → 生产或运输过程 → 供给、成本、库存或到货 → 市场影响。链条可以在任何证据不足处停下，不为形成完整故事补齐不存在的损失或价格归因。

完整日周报先按 [全球观察体系](observation-framework.md) 交代 ENSO 及全球背景，再解释区域天气，最后展开本文件的商品传导分析。某条链路证据不足时保留已知上游状态和待验证环节，不因此将整份产品缩成资料最多的局部专题。

| 研究对象 | 解释影响时需要核对的条件 |
| --- | --- |
| 农业供给 | 作物、具体产区、季节和生育阶段、异常持续时间、灌溉或土壤条件、产区权重；区分潜在单产压力与正式产量调整 |
| 矿业及能源生产 | 设施位置、实际停产或降负荷、受影响产能与预计时长、检修等其他原因、恢复情况和库存缓冲 |
| 河运、运河及港口 | 航道或设施、船型货种、限制生效时间、通行或载重变化、延误、替代路径及成本；区分降载、限流与关闭 |
| 商品及价格 | 实际可贸易供应、出口与到货节奏、库存和替代来源、需求与政策等其他驱动；气象风险不能单独解释全部价格变化 |

产量、出口能力和实际发运是不同量；设施设计能力、预约名额和实际通行量也不同。全球库存、主产国库存与可出口库存不互相替代。总量充裕可以与局部运输短缺并存，呈现对结论有实质影响的两面证据。

重要占比、损失估算和时间滞后需要数据或可追溯研究支持。没有量化依据时使用定性描述，不自行设定“红黄绿”阈值、概率或利多评分。用户要求情景分析时明确假设与触发条件。

## 气象口径

- 区分长期气候变化、ENSO 等气候变率和单次天气事件。不能仅凭同处某次 ENSO 期间，就将所有灾害归因于 ENSO 或人为变暖；明确归因需要相应研究。
- 引用 ENSO 状态时记录机构、指标定义、海区、基准期、平均窗口、发布日期及有效期。海温单次观测、周/月异常、季节平均指数和海气耦合判断不能直接互换；机构阈值与指标变化要核实当期说明，不在技能内固定一套永久阈值。
- 某状态的发生或持续概率、达到某种强度的概率、地区降雨概率和作物受损概率不能互相替代。预测与观测同图时明确区分，保留可获得的区间和不确定性。
- 地区季节性倾向不代表具体地点必然受灾，尤其不能跨季节照搬。当地气象和产业观测应补充验证。
- 单月或单年温度异常与长期气候目标使用不同时间尺度；海表温度与海洋热含量是不同指标。有关阈值的解释以机构定义为准。
- 水位站读数不直接等于航道水深或可用吃水，不将读数变化比例当成载重或运力变化比例。核对管理机构发布的实际限制。

关于长期温度目标与短期异常的口径，可参考 [Copernicus 说明](https://climate.copernicus.eu/tracking-breaches-150c-global-warming-threshold)；实际报告仍需使用当期监测资料。

## 历史比较：先确定比较问题

选择历史之前先明确需要解释的是气象强度、发展速度、产量损失、物流约束、价格反应还是恢复节奏。可以选择不同历史案例解释不同机制，不必寻找一个包办全部解释的“最像年份”。

1. **可比基础**：同一对象和单位，匹配季节、生育期或事件阶段；核对基准期、样本、时间频率与数据修订。历史峰值与本次尚在发展期的读数必须说明差异。
2. **机制相似**：解释哪条影响路径具有参照意义，而不只是两个年份都发生过厄尔尼诺或灾害。
3. **关键差异**：选择对本次结论有影响的库存、贸易格局、基础设施、适应措施、政策或需求变化，不为形式完整罗列一长串条件。
4. **可得结论**：说明历史帮助理解的程度与时滞，同时指出不能据此推出的损失规模或价格幅度。寻找能限制结论的证据，避免只选最严重案例。

有数据时用同阶段曲线或对照表；只有几个可靠节点时用节点表，不补造平滑曲线。没有适当事件时使用同季节正常范围或明确放弃类比。历史涨价同时受到其他因素作用时，不把全幅涨幅归给天气。

对“纪录”“最强”“首次”核对比较范围与记录起点。跨事件损失金额要考虑统计范围、币值和估算方式；不以持续天数或一个强度指标断言本次总损失超过历史。

## 有分寸的判断

正文自然区分“机构已报告”“机构预计”“据此可能”“仍需确认”，无需到处贴内部证据标签。后续观察要具体到能支持或改变判断的事实，如生产预估修订、限制执行与恢复、发运或到货变化。仅在权威来源或明确测算支持时给出数值阈值。
