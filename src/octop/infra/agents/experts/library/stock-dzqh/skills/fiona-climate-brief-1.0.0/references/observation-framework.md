# 全球气候与期货观察体系

## 研究体系与应用范围

这是一套面向期货投研用户的全球天气、气候与商品影响研究体系，支持问题分析、证据核验、历史比较、情景研究和持续观察。研究从用户问题出发，可从气候驱动向下分析商品影响，也可从商品或物流异动向上追溯天气条件；相关背景的深度由解释问题的需要决定。聚焦问题不要求扫描全部地区、制作文件或套用报告章节。

日报和周报沿同一体系更新，让客户从全球态势逐层理解地区变化及商品影响。完整日周报不得自行缩成单一区域、航道或品种专题；用户本来就在问局部问题时，直接按该范围研究。

以下五层构成全球研究的共同框架。完整日周报正文保持其先后关系，栏目标题可贴合当期内容；普通研究问答按问题组织相关环节，不要求逐层输出。

| 层次 | 需要回答的问题 | 应呈现的内容 |
| --- | --- | --- |
| 一、全球气候态势 | 当前处于怎样的气候背景，主导变化是什么？ | ENSO 状态、发展阶段、机构预测与修订、历史位置；有意义的全球温度和海洋背景 |
| 二、区域天气演变 | 全球背景下，各主要产区和运输区域发生了什么？ | 美洲、欧洲及黑海、亚洲、大洋洲等地区的干旱、高温、洪涝、风暴与恢复；异常范围、持续时间、所处季节及当地观测 |
| 三、商品与供应链传导 | 这些地区变化怎样影响相关期货品种？ | 产量与生产作业、能源需求与运行、库存及出口、河运与海运、到货节奏；可核实的运费、基差与期现市场反应 |
| 四、综合研判 | 多条传导路径合起来意味着什么？ | 影响在扩大还是缓和、哪些商品共振或分化、实际冲击与预期的距离、主要缓冲条件及历史参照结论 |
| 五、持续跟踪 | 下一步用什么验证或调整上述判断？ | 气候预报更新、区域天气发展、作物与生产数据、通行与装运、价格及库存验证，衔接同一观察链条 |

完整日周报开篇用短摘要概括全局判断与本期变化，然后进入第一层。摘要不能用局部事件替代全球态势介绍。历史比较贯穿相关层次，不必全部堆在独立章节；综合研判仍需说明各层证据如何共同支持结论。

## 当前观察主轴：厄尔尼诺

当前产品任务明确以厄尔尼诺态势为首要跟踪主轴。完整日报和周报开篇主体应先交代最新可核验的 ENSO 状态、强度与发展趋势，再进入区域影响；不能把它压到末尾作为无关背景。若机构本期未发新公告，仍保留最新有效状态，注明资料日期和“本期无新批次”，不因没有当日公告删除主轴。

强度、峰值、概率及纪录比较在每次运行时查证，不将某篇底稿中的“超强”“史上最强”或具体数字固化为前提。长期使用时，依据最新权威资料更新为拉尼娜或中性阶段，保留 ENSO 观察入口与同一全球研究框架；用户明确指定新主题时遵从其范围。

全面跟踪 ENSO 时，讲清当前已观测状态、后续预测及有效期、与上一有效批次的变化、与适当历史阶段的比较、主要地区的潜在影响。资料不足的项说明实际缺口，不推测补全。单项指标查询或局部商品问题只展开相关内容，不强制以 ENSO 开篇。

## 全球覆盖与区域筛选

开展全球跟踪或完整日周报时，先扫描主要产区和供应链地区，再决定篇幅。默认覆盖面包括：北美；中美洲及南美；欧洲与黑海；东南亚与南亚；澳大利亚；中国；非洲及其他关键地区按商品暴露和实际事件补充。这是全球观察覆盖清单，不是每个研究问题的必查清单，也不是预先认定每个地区发生了灾害。

日报在紧凑的区域观察总览中交代相关地区的最新状态，再详述有实质变化或持续影响的重要区域。区分“已检索、未发现重大新增”“最新资料仍为此前批次”“未取得足够资料”，不能把缺资料写成正常。气候与区域状态使用各自适当的时间尺度；月度预报、季节性干旱与每日运营公告可以共同进入一期报告，但各自标明日期。

区域层先解释异常的来源、持续性和历史位置，再在商品层展开影响。全球覆盖不等于逐国罗列新闻，也不意味着所有地区篇幅相等；要让读者看见主要区域的差异与共同变化。

## 层层衔接，不跳过上游解释

解释商品影响时，交代相关气候和地区条件。例如研究低水位时，说明相关气候背景和流域降雨、干旱的持续情况，再联系水位、通行安排、运费及商品运输。问答可以先给针对性结论再补证据；完整报告中的商品分析应能回溯前文天气背景。研究链条的完整性不等于固定每次回答的顺序。

每条重要链路按证据组织：

**气候背景与区域季节性倾向 → 当地实际天气和水文 → 产区或设施暴露 → 生产、需求或运输变化 → 商品供需、成本与市场反应。**

这一顺序是研究与解释路径，不自动证明所有因果。ENSO 对具体区域的关联以当季气象资料或研究为依据；独立天气驱动可并列呈现。不要仅为使叙事连贯，把所有地区干旱、洪灾、风暴都归因于厄尔尼诺。可在图中用明确标签区分气候背景、已确认关联和待验证环节。

商品层既要说明已发生的冲击，也要说明缓冲与恢复。涉及国内期货时，按实际贸易关系解释海外产区或物流如何经采购、装运、到港和库存传导，不直接把海外灾害等同于国内期货上涨。

## 日报与周报共用体系

- 日报：持续状态加本期新增；完整保留全球到商品的框架，压缩未变化部分，重点展开新增或仍有实质影响的环节。
- 周报：在同一框架下比较一周变化，综合区域扩散、机构预报修订、产业兑现与市场分化，加深历史比较；不是五篇日报拼接。
- 问题研究与专题：按用户实际问题聚焦品种、地区、事件或机制，交代必要背景与验证条件；用户无需先将问题命名为“专题”。只有需要成文报告时才进入文件交付流程，局部分析不能反过来成为全局日周报的默认结构。
