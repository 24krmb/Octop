# 资讯与编辑

通过公开联网检索获取新闻；用户指定其他已接入资讯工具时按该来源规则使用。先围绕观察区间宽扫宏观政策、经济数据、地缘事件、重要供应与物流变化，再深入核实波动突出的品种；同时保留影响商品的国内重大消息。

优先发布机构、交易所、政府统计部门、央行、企业公告等一手来源；需要市场解释时可用可靠媒体并标为其观点。打开来源正文核实，搜索摘要仅用于召回。去重同一事件的转载和更新，不为每个涨跌强找新闻，不用“未检索到”推断“没有事件”。

每个入选事件包含：事件发生时间、来源发布时间、主要事实、相关品种、入选理由，以及可点击原文。发布时间不明确时说明，不能用于严格历史时点报告。宏观指标明确实际值、前值、预测值各自来源；找不到可信预测值就不写“超预期”。

历史报告区分“截至当时可知”和“今天回看该假期”；前者不能引入截止后报道、后续修订和现今主力映射冒充当时情况。映射/连续序列已被更新且无法还原时披露。

## 04 关联观察：回答对国内相关品种意味着什么

围绕本期最值得关注的变化，按“外盘发生了什么 → 对哪些国内品种有什么参考意义 → 必要限制”写少量具体短段。可合并同一板块，不为每个标的凑一条。引用本报告已经有据可查的数字或事件，并把判断落到具体品种；避免只重复排行榜，也不要只列待研究的问题。

例如，原油下跌可以讨论对国内原油的价格参考及油品成本方向；两地铜价同向变化可以提示铜的外部定价背景，而不能把一个交易所的变化推广到全部有色品种。只使用已取得的映射或明确标注为一般影响分析，不凭示例扩充行情覆盖。

不默认要求库存、终端消费、利润、税费等一整套深度研究资料，不以通用核查清单充当关联观察。仅当某项已核实事实是本期核心事件、对解释变化确有必要时简要提及；用户明确追问深度基本面时再展开。合约类型、序列频度与价格口径（分钟 `last`）等属于来源口径，在文末统一说明，不占用本节。

汇率是可选的重点修正：用用户已有工具取得同期可比数据时说明其放大或抵消作用；缺失时统一注明未计汇率影响，不猜汇率方向，不输出人民币折算涨跌。没有国内行情对照时，不判断外盘变化是否已被国内消化，也不把外盘涨跌直接变成国内开盘预测。时间同步不是因果证据；媒体解释归给媒体，模型推断用条件表达。

逐项比较事件与相关价格的截止时间。后发生的事件标为“行情截止后新增事件”；不同标的截止不同则说清对象。可以讨论其后续意义，不能声称当前行情已经反映。无重大事件时缩短事件区块，不重复行情凑要点。

正文读者应无需打开来源也能理解核心事实；来源放在相应事件旁边。引用使用发布页，不链接搜索结果页。关键数据只有部分报道可核实时明确转引或证据局限。

首屏约 3 条本期要点，表达最值得关注的变化，避免“震撼”“必看”“抄底机会”等宣传式结论。行情排名按已覆盖样本展示，不叫全球全市场排名。后续追问承接报告基准与截止；若获取了更新资料，明确新增时间，不悄悄改变原报告结论。
