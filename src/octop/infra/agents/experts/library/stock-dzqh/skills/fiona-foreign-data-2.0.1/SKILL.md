# 繁微 Fiona 外盘数据

把“内盘未交易期间，相关外盘发生了什么变化”作为共同问题，覆盖日常盘前、假期与自定义区间。保留多重映射、实际数据时点和来源；外盘变化只提供参考，不能机械换算为内盘应涨应跌幅。

## 前置条件与 API Key

本 Skill 依赖 MCP server `foreign`（`/mcp/foreign`）。首次调用前先检查 `get_foreign_domestic_mapping`、`get_foreign_market_analysis` 等工具是否已就绪；工具缺失时，先按 `templates/` 中对应平台的配置接入该 MCP，具体步骤见 [接入检查与准备](references/setup.md)。工具名称及参数以当前客户端为准；客户端可能对同一 server 使用下划线、连字符或额外前缀，按功能与 schema 匹配，选已验证的一套复用，不因别名不同重复接入。

`foreign` 需要 **API Key** 鉴权。实际鉴权方式为 Bearer Token，在 MCP 客户端凭证管理区配置由服务方提供的 API Key，并以 `Authorization: Bearer <API Key>` 发送。不要把真实 API Key 粘贴到对话、Skill 文件、报告或版本库中。

API Key 申请：目前暂不支持在线自助申请，请联系繁微对口销售或项目联系人获取。

配置完成后，调用 `get_foreign_domestic_mapping` 检查映射服务，再调用 `get_foreign_market_analysis` 做一次小范围行情查询，确认实际数据可用。`401`/`403` 表示 API Key 缺失、失效或权限不足；连接失败、超时或 transport error 表示 MCP 连接不可用。行情返回为空时按覆盖区间和参数排查，不直接判定为鉴权失败。普通追问复用已验证连接，连接变化或报错时再检查。

盘前内盘对照还依赖 `futures_market_data`（`/mcp/futures_market_data`），当前公开免鉴权，**不需要 API Key**，不要配置 `Authorization` 请求头。可选的 `news`、`economic_calendar` MCP 需要 API Key，仅在本次使用时配置；端点与接入说明见 [Optional MCP 指南](references/optional-mcp.md)。

## 数据分工

- 外盘映射与行情默认使用 `foreign`，盘前内盘对照使用 `futures_market_data`。
- 假期／区间报告的新闻与事件默认公开联网检索，并打开一手来源核实，也可按需使用已接入的资讯工具。新闻检索与公开报价替代是两种用途，不把新闻检索视为可任意拼接行情的依据。
- 用户指定其他已接入来源或历史资料时按其要求使用，注明实际来源，核对时区、合约、币种、单位与价格定义。工具缺失时提供接入说明并继续可完成部分，不声称已取得行情。

## 任务选择与交付

| 用户问题 | 处理与参考 |
| --- | --- |
| 品种映射、某标的区间行情、数据口径、价差价比 | 直接回答，按需给表格；先读 [数据接入与行情口径](references/data-method.md) |
| 日盘／夜盘开盘前，内盘收盘后外盘表现 | 按 [盘前预警取数规则](references/pre-market-warning.md) 对齐内盘交易时段与外盘窗口；只有请求报告时生成文件 |
| 假期观察、节后复盘、自定义区间观察报告 | 按 [假期与区间观察](references/interval-watch.md) 组织行情与同期事件，默认使用随包模板生成中文单文件 HTML；用户指定其他形式时遵从 |
| 品种／事件追问，更新已有报告 | 承接已有区间和证据直接回答；更新时重新取数、保留原基准，核实新增事件并另存版本 |

同一任务只读共用行情口径和当前场景参考一次；连接已验证时无需重读 setup，只有生成文件才读 presentation，只有需要资讯才读 editorial。固定风险提示首次读取后复用，不因追问或两个场景来回切换反复加载。

用户给出的品种、年份和起止时刻优先。未指定区间的盘前问题按交易时段确定窗口；假期问题采用上下文唯一可确定的假期，不能唯一确定时询问。未来假期不能生成尚未发生的表现；明确要求预览或模拟时标注假设，不编造行情、官方休市安排或国内反应。

## 共用行情规则

执行行情任务前阅读 [数据接入与行情口径](references/data-method.md)，其中统一维护频度阈值、聚合限制、端点计算及合约规则。

- `frequency`、`max_points`、`aggregation` **仅影响分钟序列**。区间涨跌、高低价等统计始终取原始数据口径，不使用分桶后的序列端点计算区间涨跌。需要自定义基准时核实同口径原始端点。
- `max_points` 默认 1500，范围 1~1500，1500 为硬上限；未传频度或空串时按跨度分档，超限沿 1m→5m→15m→30m→60m 降频，60m 仍超限则保留最新部分、丢弃最老数据。降频只根据查询跨度估算，与品种及实际记录数无关；手动频度只能向更粗档调整。
- 1m 禁止传 `aggregation`，包括未指定频度而自动选到 1m 的情况，传入返回 400。粗档可选桶内最新、最早、最高或最低价，整点分桶、左边界标签；标签不是原始取价时刻。
- 外盘记录自 **2026-08-26 18:00（北京时间）** 开始积累。全区间早于起点时无法用此源验证，建议近期区间或同口径历史资料；跨越起点时按实际首条记录说明可用起点与缺失区间，不冒称覆盖完整。
- 合约类型以映射实际返回为准：多数为成交量换月主力连续，LME 为三个月连续，新加坡与马来西亚交易所按成交量稳定性选择连一／连二／连三。不统一标成主力连续。
- “最新”指最新已同步行情，非实时。报告同时列请求窗口、统计实际首末时间；使用序列时另外列实际频度、条数、首末标签及截断情况，不能用序列覆盖替代统计覆盖。

## 分析与输出

先给回答本次问题的核心结论，再提供对应标的、交易所、合约类型、价格单位、涨跌与实际时间。保留多个有效外盘映射，说明差异；去重同一交易所、代码与价格口径的外盘标的，没有代码时用交易所与名称，不编造代码。

`get_foreign_domestic_mapping` 不传两个筛选参数可取全量目录；多品种或全范围任务可一次获取并本地筛选，单品种优先按代码查询，同一任务复用目录。目录规模、板块和多重映射以实际返回为准，不固定数量。开始取数时简述本次品种与窗口；用户指定四个品种就查这四个，不自动扩成全市场。未指定品种的扫描说明实际扫描范围。按原始区间统计的绝对涨跌幅选择重点（默认前 5），不混排不同单位的绝对价差；缺失或不可比项单列。默认先取原始统计，只有画路径或排查明显异常才取序列；允许时可并发独立查询，按服务限制控制并发，不重复获取已满足本次需求的同窗口数据。相关性类别不是相关系数，没有历史样本时不声称已估计映射误差或置信区间。

盘前可结合内盘对照给出可能高开／低开／中性的辅助判断及不确定性；假期观察以已发生变化和国内关联为主。均不承诺方向、不输出买卖点、仓位、目标价或委托指令。价格路径需由有效序列支持，最终涨跌不能代表全程走势。

新闻事实、媒体解释和 AI 推断分开。事件晚于相关标的行情截止时，标为“行情截止后新增事件”，不能用于解释此前涨跌。资讯核实见 [资讯与编辑](references/editorial.md)。换汇与跨市场价差先统一单位、币种和时点，见 [汇率数据与换算](references/exchange-rate.md)；无可比汇率则注明未计汇率影响，不输出人民币推算。

公开报价补充按用户要求使用并披露来源、URL、报价时刻和检索时刻；不能把不同来源的两端价格拼成区间涨跌。资料不完整时交付已核实部分并列缺口，不填零、不以演示数据替代。HTML 交付和底稿字段见 [HTML 交付](references/presentation.md)。

## 风险提示

实质性回答及可展示产出物末尾保留 [固定风险提示](references/disclosure.md)。仅数据整理使用普通提示；涉及方向、趋势、影响或情景使用加强提示；接入说明、报错和澄清不附。结构化输出携带 `risk_level`、`risk_disclaimer`，渲染器使用同一文本，不使用研究员署名或机构审核标志。
