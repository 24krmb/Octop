# 日报与周报编辑

仅在用户需要日报或周报时使用本文件。普通研究问答、历史比较、核验和连续追问使用共同研究方法，按问题回答，不自动进入报告编排。

## 统一体系，逐期更新

完整日报和周报以 [全球观察体系](observation-framework.md) 的五层结构组织。产品名、观察范围和研究层次稳定；当期标题、重点地区、图表与篇幅随资料变化。编辑工作的目标是让客户从全球态势逐步理解区域天气及期货相关影响。

开篇简短概括本期全局判断与主要变化，然后依次进入全球气候态势、区域天气演变、商品与供应链传导、综合研判和持续跟踪。不要根据最容易取得数据的一条消息重定产品主题。独立的深度专题仅在用户明确要求时生成。

## 筛选与层级

先检索完整覆盖面，再在每个层次内选择最有价值的信息：

- **持续重要性**：ENSO 演进、重要地区持续干旱等即使没有当日新公告，仍可能是理解全局必需的背景。
- **新增程度**：新事件、预报修订、范围扩大、实际损失确认、恢复或风险解除；文章刚被转载不等于事件刚发生。
- **商品相关性**：涉及哪些主要产区、消费地区、设施和通道，影响处于什么环节，规模有何依据。
- **关键时点**：天气与播种、生长、收获、旺季用能、集中出口及运输窗口的交会。
- **解释价值**：哪些证据体现跨区域共振或分化，哪些历史参照帮助理解程度、节奏与本次差异。

全球气候重要动态精选少量重要信息，原始需求的 1—3 条可作为这一层的起点，不是整份报告只覆盖一两个地区的理由。条数为编辑参考，用户明确要求优先。地区扫描与商品影响另行组织，不能由一条当地事件占据绝大部分正文。

## 各层怎样衔接

- **全球层**：先让客户知道当前 ENSO 状态及变化、预测有效期和历史位置。重要的全球高温或海洋背景按证据补充。
- **区域层**：先用区域总览展示主要地区状态，再展开重要异常。解释地区、季节、持续性及与气候背景的关系，不逐家复述发布机构。
- **商品层**：每个重要影响指向前文对应地区，按生产供给、需求与能源运行、运输与到货等路径组织，交代相关期货品种。上游背景已经说清后，用简短回指避免重复。
- **综合层**：回答气候影响正在扩散、强化、分化还是缓和，哪些环节已兑现、哪些由库存或替代供应缓冲。综合判断要整合前文，不能只是再次列举事件，也不能为形成统一方向忽略反证。
- **跟踪层**：将验证信号对应上述判断，包含气候状态、区域异常和产业兑现三个层面，不只列局部运输指标。

例如，读者应先在全球层理解气候阶段，再在区域层理解相关流域降雨与干旱，最后在商品层读到低水位、限流、运费与出口节奏。存在其他气候驱动或归因不确定时如实表达；研究顺序不代表可以省略因果证据。

## 日报：持续态势加本期变化

日报既提供截至本期的全球观察截面，也说明哪些环节出现新增。全球背景用最新有效批次，区域异常用相应监测期资料，运营变化用当日或近期公告；分别标注来源日期。本期窗口外但仍有效的状态可以保留，不伪装为今日新闻。

固定框架下，未变化部分简写，新变化和仍有重大影响的环节展开。ENSO 本期无新公告时明确沿用哪一期状态，不把“未核验到新公告”写成一大段研究结论，也不省略 ENSO 观察。

没有重大新增时仍给简洁的全局跟踪更新，区分持续状态、恢复及资料缺口。不能为了保持新鲜感改写成单一航道专题或临时科普。

## 周报：沿同一体系比较变化

周报重新核对一周的资料批次、地区进展、产业修订和恢复情况，不能拼接日报或延续已失效的数字。加深以下内容：

- ENSO 及全球背景相对前一有效批次如何变化，机构间分歧在哪里。
- 哪些地区的异常扩散、持续或缓和，哪些地区方向不同。
- 天气风险在哪些商品或运输环节转化为事实，哪些预期尚未兑现。
- 历史参照在哪些条件上适用，本次哪些缓冲或叠加因素改变结论。
- 对下周全球态势及重点品种观察作何调整。

已有前期报告时追踪判断的维持、强化、减弱或修正；没有前期报告时比较已取得的资料批次，不捏造预测记录。日报、周报使用同一观察体系，变化的是时间跨度与综合深度。

## 文字、图表与阅读检查

一级标题对应全球、区域、商品、综合和跟踪层次，二级标题可用具体判断或问题。先给认识，再给证据与比较；图表帮助读者看见全球位置、地区分布及传导链条，不能只给某个局部事件配精美图形。

重要局限在对应判断处简要交代；单位、批次与一般核验说明放图注和来源说明。正文重点解释已知信息及其意义，避免反复以“不能据此推导”收尾。

交稿前只读标题、导读、图题和综合判断，应能复述当前全球气候状态、主要地区差异与商品影响。然后检查每个重要影响能否回溯对应天气，是否有地区被遗漏或被错误写成没有异常。图文专业度与全球研究覆盖须同时成立。

## 连续记录与更正

有前期报告或事件记录时复用待观察事项并核对本期变化。持续生产可保存轻量底稿：气候批次、区域状态、相关商品、当前证据、待验证变化；不要求为一次日报搭建数据库。关键事实错误明确更正，正常预测修订说明新批次与调整依据。生成报告不自动建立定时推送或对外发布。
