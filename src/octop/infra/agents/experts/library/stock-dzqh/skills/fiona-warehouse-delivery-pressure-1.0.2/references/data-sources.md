# 数据源与工具规范

## futures_market_data

主要使用：

- 交易日历和最近交易日；
- 品种、可交易合约、具体合约信息和交易参数；
- 具体月份合约日线或快照的价格、成交量和持仓量；
- 仓单数量、仓单单位和仓单折合合约手数；
- 仓库汇总与注册仓库位置；
- 必要时查询临月会员多空持仓。

注意：

- 仓单接口附带的期货持仓量是品种级数据，计算交割覆盖率时另取目标月份合约持仓。
- 仓库分布如果只有注册仓库名录和地址而没有各仓库仓单数量，只能描述可用交割网络，不能计算实际地域集中度。
- 仓单显式日期区间最多 60 个自然日、最多 3 个品种，单次最多 500 行；长历史分段查询并去重。
- 合约信息中的最后交易日不能替代完整交割规则。缺少交割期、限仓、注销或资格规则时查交易所官网。

## dzlabel

用于寻找广义产业库存，不用于替代注册仓单：

1. `get_products` 获取品种 ID；
2. 用 `search_indicators` 搜索“社会库存”“库存”“港口库存”“工厂库存”“保税库存”等；
3. 搜索失败时缩短关键词，必要时逐层展开目录；
4. 选择少数与品种供应链最相关且统计范围清楚的指标；
5. `get_indicator_series` 必须显式传入当前所需起止日期，不依赖工具的静态默认日期。

检查指标的名称、完整链路、单位、频率、来源、公式、起止日期和最新数据日。不同供应商库存口径可能重叠，不汇总求和。

## Web Search

优先从以下交易所官方域名查询：

- 上海期货交易所：`shfe.com.cn`
- 上海国际能源交易中心：`ine.cn` 或上期所能源中心页面
- 大连商品交易所：`dce.com.cn`
- 郑州商品交易所：`czce.com.cn`
- 广州期货交易所：`gfex.com.cn`

主要补充：

- 仓单日报和有效预报；
- 指定交割仓库库存周报；
- 历史实际交割量；
- 合约及交割业务细则；
- 仓单有效期、集中注销、品牌品级和升贴水；
- 交易所临时公告和规则调整。

使用原始网页、PDF、Excel 或公告，保留直接链接，并区分发布日期、统计截止日和适用合约。搜索摘要只用于定位，不作为最终数值来源。官方资料无法取得时可使用可靠行业来源补充，但标明来源等级。

## 数据降级

- 无有效预报：用仓单、指定库合格库存和广义库存描述补货环境，不估算预报转化。
- 无指定库库存周报：只把注册仓单视为确认供给，社会库存作为辅助。
- 无历史交割量：只分析最大潜在压力和持仓异常，不预测实际交割规模。
- 无完整规则：不得对交割资格、仓单有效性或强制退出节点作确定判断。
- MCP 不可用：可用交易所公开资料完成部分研究，但必须说明持仓、仓单历史或单位转换的缺失。
