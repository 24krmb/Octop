# ak-fund-flow — 资金面监控技能

## 1. 何时使用

判断"钱往哪走"的一切场景：个股主力资金动向、板块轮动的资金证据、龙虎榜席位分析、
两融情绪监控、大盘资金面冷暖。本技能输出的是**资金面事实与统计特征**；
把资金面与价格行为结合成交易信号属于 Signal 岗的活，两步之间不要混在一张表里偷懒。

## 2. 核心口径提醒（先读，防误读）

1. **"主力净流入"是算法产物，不是事实披露。** 东财口径按单笔成交金额分档（超大单/大单/中单/小单）推算主动买卖方向。它是"大单主动性净额"，与真实主力行为有偏差——小单拆分、算法交易都会污染口径。报告引用时必须写明"东财大单口径"。
2. **北向实时数据已停披。** 沪深港通自 2024 年 8 月起不再披露北向实时买卖净额，任何"今日北向净买入 X 亿"的实时说法已不可得；可用的只有历史汇总与持股口径（见 §3）。凡用户问"今天北向流入多少"，先说明该数据已停止实时披露。
3. **资金流数据是横截面+时序混合体。** "今日"接口盘中取数是未收盘快照，尾盘会变；正式结论用收盘后数据，并在报告中标注抓取时间。
4. **限频。** 资金流类接口多为东财源，批量取数间隔 ≥1 秒，遇空返回先怀疑限频而不是接口失效。

## 3. 接口速查表

> 接口名以 akshare 1.1x 为基准；报错时用 `[i for i in dir(ak) if '关键词' in i]` 检索，
> 并查官方文档 akshare.akfamily.xyz。调用后先 `print(df.columns.tolist())`。

### 个股与大盘资金流

| 需求 | 接口 | 说明 |
|---|---|---|
| 个股历史资金流 | `ak.stock_individual_fund_flow(stock, market)` | `stock="000001"`, `market="sz"/"sh"`；历史逐日超大单至小单明细 |
| 个股资金流排名 | `ak.stock_individual_fund_flow_rank(indicator="今日")` | `indicator`: 今日/3日/5日/10日；全市场横截面 |
| 大盘资金流 | `ak.stock_market_fund_flow()` | 沪深两市历史逐日汇总 |
| 行业板块资金流 | `ak.stock_sector_fund_flow_rank(indicator="今日", sector_type="行业资金流")` | `sector_type`: 行业资金流/概念资金流；板块轮动的资金证据 |
| 板块内个股资金流 | `ak.stock_sector_fund_flow_summary(symbol)` 类接口 | 以 `dir(ak)` 检索 `sector_fund_flow` 族为准 |

### 龙虎榜 / 大宗交易

| 需求 | 接口 | 说明 |
|---|---|---|
| 龙虎榜明细 | `ak.stock_lhb_detail_em(start_date, end_date)` | 日期格式 `YYYYMMDD`；含涨跌幅、龙虎榜净买额等 |
| 席位/个股追踪 | `ak.stock_lhb_*` 接口族 | 用 `dir(ak)` 检索 `lhb`，按需求选个股月频/机构席位/营业部统计等 |
| 大宗交易统计 | `ak.stock_dzjy_mrtj()` | 每日汇总；明细类接口用 `dir(ak)` 检索 `dzjy` 族 |

### 北向（沪深港通）与两融

| 需求 | 接口 | 说明 |
|---|---|---|
| 北向历史资金流向 | `ak.stock_hsgt_hist_em(symbol="北向资金")` | 历史逐日口径；`symbol` 可取 北向资金/沪股通/深股通（以接口文档为准） |
| 沪深港通汇总 | `ak.stock_hsgt_fund_flow_summary_em()` | 汇总口径；**注意 2024-08 后实时净买入已停披** |
| 融资融券（沪） | `ak.stock_margin_sse(start_date, end_date)` | 交易所披露口径，T+1 日更新 |
| 融资融券（深） | `ak.stock_margin_szse(date)` | 同上；两融合计=沪+深，注意披露滞后 |

## 4. 标准工作流

1. **定口径：** 明确监控对象（个股/板块/大盘）、时间窗（今日/3日/5日/10日/区间累计）、数据源。
2. **取数：** 按速查表调用；东财系逐次间隔 ≥1 秒；收盘后数据为准，盘中数据标注"盘中快照"。
3. **清洗：** 列名确认 → 缺失检查 → 金额单位统一（万元/亿元，东财多为元，报告统一换算为亿元保留 2 位）。
4. **分析三板斧：**
   - **方向：** 净流入/流出连续 N 日的方向性统计；
   - **强度：** 主力净流入额/成交额 比值（消除流动性差异，才能跨票比较）；
   - **背离：** 价格新高 vs 主力净流入萎缩的背离信号（描述统计，不下结论）。
5. **交付：** 表格输出 + 口径声明（数据源、指标算法口径、抓取时间戳）+ 风险提示。

## 5. 常见坑

1. **把"主力净流入"当涨跌预测用。** 资金流与次日收益的相关性弱且不稳定，报告里禁止出现"主力流入=要涨"式表述。
2. **龙虎榜当日数据尾盘后才完整**；盘中查询会产生"今日上龙虎榜"的不完整误判。
3. **两融数据 T+1 披露**，"今日两融"实际是昨日值，报告需标注。
4. **行业/概念板块口径漂移**：东财会调整板块成分，跨期对比板块资金流时注明"以当前成分快照为准"。
5. **单位混乱**：东财资金流接口返回单位为"元"，直接当"万元"用会差一万倍——每次取数先看量级。

## 6. 交付标准

- 所有金额统一"亿元（保留 2 位小数）"，方向用 +/− 号。
- 每张表注明：接口名、指标口径（如"东财大单口径"）、抓取时间戳、盘中/收盘后。
- 结论只描述资金面事实与统计特征；信号化解读交由 Signal 岗按研究单流程处理。
