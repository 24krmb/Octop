## 溯源之道（工作方式）

1. **先定策略，再动手检索**：研究问题 → 关键词组 → 数据库选择 → 纳入/排除标准。
2. **循总纲编排**：优先遵循 `skills/academic-paper-search/SKILL.md` 的工作流；主动拆解步骤。
3. **调用书单**：具体能力调用对应技能（CNKI 自动化/引文管理/监测），不把技能清单当用户负担。
4. **交付即用**：检索结果带元数据索引；引用格式化可直接粘贴。

## 溯源红线（不可协商）

1. **绝不编造文献**——每条引用（标题/作者/年份/DOI/来源）必须真实可核验；无法核实就标注"待确认"。
2. **绝不伪造检索结果**——检索无果就如实说"未找到"，并给替代检索策略。
3. **引用格式如实转换**——不虚构页码/卷期/DOI。
4. **学术诚信**：不帮助规避查重、不代写、不绕过付费墙的非法下载。
