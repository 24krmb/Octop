# ak-risk-control — 风控与仓位管理技能

## 1. 何时使用

两类时刻：① 用户问"买多少/止损设哪/能亏多少"；② 任何策略结论即将输出为
"建议执行"级内容之前（强制风控评审）。本技能的信条：**收益是市场给的，
纪律是自己的；先确定愿意亏多少，才轮到讨论能赚多少。**

## 2. 仓位三大方法（内置脚本支持，参数含义锁死）

### 方法一：单笔风险预算（默认首选）

> 仓位 = (总资金 × 单笔风险比例) ÷ (入场价 − 止损价)

- 单笔风险比例默认 ≤2%（激进 ≤2%，稳健 1%，试仓 0.5%）——**这是团队红线，不是建议**。
- 直觉解释：这一笔打止损，账户疼多少。仓位不是"感觉能买多少"，是从"愿意亏多少"倒推的。
- A股注意 100 股整数倍向下取整；取整后实际风险 ≤ 预算值，需回算实际风险展示。

### 方法二：ATR 波动率头寸（让波动决定仓位）

> 止损距离 = k × ATR14（k 默认 2.0，即 2 倍日均真实波幅）
> 仓位 = (总资金 × 单笔风险比例) ÷ (k × ATR14)

- 高波动品种自动缩仓，低波动品种自动放大，天然实现"波动率平价"的朴素版。
- ATR 用前复权日线计算（`ak-technical-indicators` 技能）；期货用主力连续。

### 方法三：Kelly 分数（折扣版，慎用）

> f* = 胜率 − (1 − 胜率) ÷ 盈亏比；实际仓位 = f* × 折扣系数（默认 0.5，即"半 Kelly"）

- 输入的胜率/盈亏比必须来自 Echo 岗回测单，禁止拍脑袋。
- Kelly 对输入误差极其敏感，**永远使用折扣版**；回测样本 <100 笔时再打半折。

### 期货附加核算（必须项）

- 保证金占用 = 合约乘数 × 价格 × 手数 × 保证金率；占用比例建议 ≤40%。
- 强平距离 ≈ 净值回撤到维持保证金线的幅度；入场前必须算"反向波动多少个 ATR 会强平"。
- 杠杆是仓位的一部分：名义敞口 = 合约乘数 × 价格 × 手数，**风控看名义敞口，不看占用资金**。

## 3. 止损止盈体系（三件套缺一不可）

| 类型 | 规则 | 说明 |
|---|---|---|
| 初始止损 | 技术位或 2×ATR，与仓位联动 | 下单前确定，写进计划，不临场改 |
| 移动止损 | 盈利后跟踪（如跌破 20 日线或回撤 1×ATR 离场） | 只上移不下移（多头） |
| 时间止损 | N 个交易日内未按预期发展即离场 | 防"僵尸仓位"，默认 20 日 |

**回撤红线（组合级，不可协商的默认值）：** 组合自高点回撤 ≥8%：仓位减半；≥12%：
只留底仓并暂停新开仓；≥15%：清仓复盘。红线触发不需要理由，执行不需要勇气，
这就是把红线提前写下来的意义。

**集中度红线：** 单票 ≤20%、同行业 ≤35%（用户另有声明的以其为准，但必须显式记录）。

## 4. 内置脚本：position_sizer.py

```bash
# A股：单笔风险预算 + ATR 联动
python3 "skills/ak-risk-control/scripts/position_sizer.py" equity \
    --capital 1000000 --risk-pct 0.01 --entry 12.50 --stop 11.80

# 期货：保证金与强平距离核算
python3 "skills/ak-risk-control/scripts/position_sizer.py" futures \
    --capital 1000000 --risk-pct 0.01 --entry 3850 --stop 3720 \
    --multiplier 10 --margin-rate 0.12 --contract-ratio 0.5

# Kelly 折扣仓位（输入必须来自回测单）
python3 "skills/ak-risk-control/scripts/position_sizer.py" kelly \
    --win-rate 0.55 --win-loss 1.4 --fraction 0.5 --capital 1000000 \
    --entry 12.5 --stop 11.8
```

脚本输出：建议手数/股数（A股自动取整百）、实际风险金额与比例、（期货）保证金占用、
名义敞口、反向波动强平距离，以及一份可粘贴进风控意见书的结构化摘要。

## 5. 风控评审输出（对接 Sentinel 岗意见书）

三档结论，禁止骑墙：
- **通过**：附仓位/止损/集中度参数，进入报告"建议执行"级；
- **有条件通过**：列出必须满足的约束（如"缩量至半仓""止损上移至成本价后才可加仓"）；
- **否决**：列出理由（缺止损位/超集中度/回撤红线触发/杠杆超限），一票否决即生效。

## 6. 常见错误（每个都让人亏过真钱）

1. **先定仓位再定止损**——顺序反了。正确顺序：止损位 → 单笔风险 → 仓位。
2. **用"亏了再加仓摊薄"替代止损**：摊薄是给错误加杠杆，团队禁止以摊薄为目的的加仓。
3. **满仓单票 + 期货满杠杆**：任何一项触发集中度/保证金红线，直接否决。
4. **止损位设在"心理整数位"**：应设在结构位（前低/均线）或 ATR 倍数，整数位是全世界止损单的坟场。
5. **回撤红线临场商量**：红线只在冷静时签署一次，触发时只执行不复议。
