# ak-backtest — 回测工作流技能（框架无关）

## 1. 何时使用

任何"策略靠不靠谱"的问题都由本技能回答。典型触发：验证均线策略、测因子有效性、
对比参数组合、算夏普与回撤、评估信号样本外表现。
本技能**刻意不绑定框架**：backtrader/vectorbt/自研引擎各有适用场景，但方法论与诚实度
与工具无关。换任何工具，本技能的流程与红线都适用。

## 2. 回测前检查单（Echo 岗执行；五项缺一不开跑）

1. **规则自洽：** 信号规则完整（入场/出场/方向/频率），且**生效延迟明确**——T 日收盘数据生成的信号，T+1 日才能成交。这是回测作弊的头号来源。
2. **数据口径：** 前复权、无幸存者偏差的标的清单（注意：用今天的股票名单回测十年前 = 幸存者偏差，选股型回测必须用历史时点可得的名单并声明局限）。
3. **成本假设：** 默认佣金万 2.5/单边 + 滑点 0.1%（流动性差的票上调至 0.3%+）；期货另计平今仓手续费差异；成本假设必须在结果中显著标注。
4. **样本切分：** 训练/测试集明确（常用 70/30 按时间切，**绝不随机打散**）；测试集在最终定稿前只允许看一次。
5. **基准定义：** 必须有对照基准（如沪深300 `000300`、行业指数），"跑赢基准"才是策略有效的最低门槛。

## 3. 标准工作流

1. **准备：** 用 `ak-market-data` 取数 → `ak-technical-indicators` 补指标列。
2. **实现：** 简单日频策略优先用向量化实现（见 `references/backtest_template.py`，纯 pandas、逐行注释、自含演示数据可离线跑通）；复杂事件逻辑（止损单、条件挂单）再考虑事件驱动框架，并保持同一套成本/执行假设。
3. **首轮回测：** 训练集跑通 → 产出净值曲线 + 交易明细 → 用 `ak-quant-report` 的 performance.py 统一口径算绩效（禁止手算指标）。
4. **稳健性三连（强制）：**
   - **样本外：** 测试集复跑，披露衰减幅度（训练夏普 2.0 → 测试 0.4 = 红灯）。
   - **参数敏感性：** 核心参数 ±20% 扰动，结果剧变说明策略"住在参数上"。
   - **分年切片：** 分年度收益表，检查是否依赖单一年份（如只赚 2019 一年的钱）。
5. **诚实报告：** 按【ECHO 回测单】格式交付；"缺陷与警告"栏不许空。

## 4. A股/期货执行假设（默认值，除非用户显式改）

| 项目 | A股 | 国内期货 |
|---|---|---|
| 执行时点 | 信号 T 日收盘生成，T+1 开盘价成交 | 同左（日线级别） |
| 成交约束 | 涨跌停/停牌不可成交，顺延至可交易日 | 涨跌停板不可成交 |
| 交易成本 | 佣金万2.5/单边 + 卖出印花税 0.05% + 滑点 0.1% | 手续费按品种 + 滑点 1 tick |
| 资金约束 | 100 股整数倍；不考虑融资融券（除非声明） | 保证金率按品种声明，另算强平距离 |
| 其他 | T+1 制度：当日买入不可当日卖出 | 主力换月需声明处理方式（直接切换/按持仓量加权） |

## 5. 过拟合审查（红灯清单，命中任意一条须显著警示）

- 参数优化后夏普远高于未优化版本（提升 >50%）；
- 信号规则里出现"看起来是看着行情编的"硬编码日期/价格；
- 测试集被反复使用调参（数据窥探）；
- 训练/测试表现衰减 >60%；
- 年化收益 >50% 且回撤 <10% 的日线策略（先怀疑实现错误：未来函数、成本漏算、成交价用了当日收盘）。

## 6. 未来函数排查（回测错误 80% 来自这里）

1. 用 T 日收盘价算指标又按 T 日收盘价成交（应 T+1）；
2. 用了 T 日才公布的财务数据做 T 日信号（财报有公告延迟，用 `ann_date` 公告日对齐）；
3. 全期归一化/标准化（用了未来数据的最小最大值）；
4. 停牌日用当日不可得的价格"补齐"；
5. 幸存者偏差名单（见 §2）。

## 7. 交付标准

- 净值曲线 CSV（date, nav, benchmark_nav）+ 交易明细 CSV（含成交价、成本、理由字段）。
- 绩效指标必须由 `ak-quant-report` 脚本统一计算，标注成本假设与执行假设。
- 结论分三档：**可进入风控评审 / 需改进后复测 / 证伪**；不给"未来会赚钱"式预测。
